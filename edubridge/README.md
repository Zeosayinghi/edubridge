# 橋學 EduBridge

偏鄉教育平台 — 讓每個角落的孩子都能追上城市的腳步。

## 功能特色

- 📚 開放式課程庫（YouTube + 補習班老師無償提供）
- 📝 影片逐字稿 ＋ BERT 心智圖
- 🎯 智慧考試系統 ＋ 錯題複習
- 🤖 AI 學習助理（24 小時）
- 📊 觀念能力分析儀表板
- 🌿 人文導師關懷系統

## 部署

本專案部署於 [Vercel](https://vercel.com)，推送至 `main` 分支即自動上線。

## 安全機制

- 動態浮水印（帳號 ＋ 時間戳）
- 政府驗證帳號 ＋ 單一裝置綁定
- DRM 串流加密
- 完整觀看稽核紀錄
